# React Practice Assignment

A beginner-friendly ReactJS project built to practice fundamental React concepts including Components, Props, State Management, Hooks, Routing, API Integration, and TailwindCSS.

---

## Project Overview

This project contains multiple mini applications combined into a single React application using React Router.

Each feature is implemented on a separate route/page to practice component-based architecture and client-side routing.

The project focuses on:

* React Components
* JSX
* React Router
* useState Hook
* useEffect Hook
* Custom Hooks
* Event Handling
* Forms
* CRUD Operations
* API Calls
* TailwindCSS Styling

---
